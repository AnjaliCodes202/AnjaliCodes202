## 📊 Featured Projects

### 🤖 AI Study Buddy
An intelligent, full-stack RAG ecosystem designed to streamline student workflows by converting dense lecture material into structured, interactive study modules.
* **Document & Video Pipeline:** Parses, cleans, and chunks multi-format lecture files (PDFs, PPTX, Docs) and extracts transcripts from video/YouTube sources into optimized vector structures using FAISS.
* **Interactive AI Features:** Implements low-latency context retrieval via LangChain and Groq (LLaMA-3) APIs for specialized semantic Q&A ("Chat with Lecture"), automated assignment breakdown, and summary generation.
* **Active Learning Generation:** Programmatically builds custom interactive quizzes (MCQs, short answer) and flashcards supporting spaced repetition.
* **Management Ecosystem:** Built native lecture course compilation organizers, assignment tracking boards, secure user authentication workflows, and persistent activity history storage using MongoDB.

### 💬 Real-Time Messaging Application
A highly scalable, production-ready chat environment engineered for instant communication.
* Built full bidirectional communication channels utilizing Socket.io for low-latency, room-based messaging and global broadcasts.
* Implemented secure session handling with JWT authentication and protected access routing.
* Optimized UI performance and state transitions utilizing Zustand, ensuring minimal DOM re-renders.
* Styled fully responsive layouts using TailwindCSS alongside structured Node.js/MongoDB RESTful APIs.

### 🛠️ RAG Pipeline Optimizer & Evaluation Dashboard
A developer tool engineered to analyze, compare, and grade RAG system variants.
* Designed modular FastAPI backend services to easily swap and evaluate alternative chunking policies, embeddings, and retrieval depths.
* Configured automated LLM validation suites scoring pipeline output configurations on relevance, truthfulness, and architectural latency.
* Rendered live performance trade-offs, cost matrices, and search metrics using an interactive React frontend dashboard.
